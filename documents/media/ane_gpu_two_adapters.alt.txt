Sequence diagram, "Two documents, two adapters", with three lifelines: Host (CPU, document in memory), Neural Engine (resident 0.6B base), GPU (27B, reasoning off). Document 1, an ISDA Schedule, 12.5 s end to end: the host binds adapter IS3 (73 ms, 9.2 MB); in a loop over 44 windows it sends each window to the Neural Engine and gets hidden states back (29 ms per window, 1.5 s for 44); it picks 17 of 44 windows and sends their text as a prompt to the GPU (4,862 of 9,696 tokens); the host restores the default adapter CUA (71 ms) while the GPU is still answering; the GPU returns 12 answers (11.0 s). Document 2, an arXiv paper, 14.6 s end to end: bind AX2 (81 ms), 66 windows (2.2 s), 19 picked, a 5,339 of 14,617 token prompt, CUA restored (74 ms), 12 answers (12.4 s). The only thing the GPU receives is text. Stage times are from the run in the posted video.
